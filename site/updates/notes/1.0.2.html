Captylo 1.0.2

New

  • Voice messages from chat apps in File transcription: .ogg and .opus files, for example from WhatsApp or Telegram. Voice messages saved without an extension in the name (for example voice_04-10-2026_21-03-40) work too: Captylo recognizes the format from the file's contents. Drag the file onto the window or pick it with Choose files.
